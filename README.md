# 📊 Heart Disease Data Analysis Project  
### ❤️ Predictive Insights for Heart Disease Risk  


Welcome to my **Heart Disease Data Analysis project!** This repository contains a comprehensive analysis of **clinical and demographic data** related to heart disease. Using **SQL**, **Python**, and **Power BI**, this project explores key risk factors, patient demographics, and prediction patterns to better understand and predict heart disease risks.

---

## 🔍 **Project Overview**  
This project analyzes a real-world dataset containing clinical and lifestyle information with over 15+ relevant features, including:  
- **Patient Demographics:** Age, Gender, BMI, etc.  
- **Clinical Measurements:** Blood pressure, cholesterol levels, ECG results, etc.  
- **Lifestyle Factors:** Smoking, physical activity, diet habits.  
- **Heart Disease Status:** Presence or absence of heart disease (target variable).  
- **Risk Scores & Metrics:** Various calculated indicators to evaluate risk severity.  

---

## 🛠️ **Tools & Technologies**  
- **SQL:** For data wrangling, cleaning, and exploratory analysis.  
- **Python:** Data preprocessing, visualization, and machine learning modeling.  
- **Power BI:** Interactive dashboard creation and reporting.  

---

## 🏆 **Key Features & Highlights**  
- Detailed exploratory data analysis identifying major risk factors.  
- Classification models built using Logistic Regression, Random Forest, and XGBoost to predict heart disease presence.  
- Achieved classification accuracy of **85%+** with model tuning.  
- Visualized correlations between features and heart disease outcomes.  
- Interactive dashboards to track patient risk profiles and trends.  

---

## 📈 **Model Evaluation**  
- **Accuracy:** 85%+ on test dataset  
- **Precision & Recall:** Balanced to reduce false negatives  
- **ROC-AUC:** 0.90 indicating strong model discrimination  
- **Feature Importance:** Cholesterol, Age, Blood Pressure identified as top predictors  

---

## 📊 **Dashboards & Insights**  
- **Power BI Report:** Visualizes risk factor distributions, prediction results, and demographic breakdowns.  
- **Interactive Dashboard:** Allows filtering by age, gender, and clinical parameters to analyze subgroups and trends.
